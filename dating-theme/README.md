# Dating App Theme

A simple WordPress theme inspired by modern dating applications. It is mobile-first and features a clean layout with a bold accent color.

## Installation

1. Copy the `dating-theme` folder into your WordPress `wp-content/themes` directory.
2. Activate **Dating App Theme** from the WordPress admin panel.
3. Customize as desired.

## Features

- Responsive design for mobile and desktop
- Minimal layout using standard WordPress loops
- Easy to extend with your own styles and templates
- Posts on the home page appear in a profile grid layout
